# Ficha de Atendimento — Manifestações Cliente Sabesp (layout oficial)

Descrição do modelo oficial. O PDF de exemplo recebido **não** foi versionado porque contém dados reais de uma moradora.
O formato não pode ser alterado: a aplicação deve preencher este layout, e não redesenhá-lo.

**Cabeçalho (todas as páginas):** "FICHA DE ATENDIMENTO – MANIFESTAÇÕES CLIENTE SABESP" / "EM – DIRETORIA DE GESTÃO DE EMPREENDIMENTOS DE ESGOTO DA RMSP" + logotipo Sabesp à direita.

**Quadro 1:**
- Empresa contratada: Consórcio Performance Tamanduateí
- Responsável pelo atendimento
- Data · Horário
- Local (ex.: CAC Itinerante)
- Assunto
- Tipo de manifestação (Reclamação, Solicitação, …)

**Quadro 2 — Dados do cliente:** Nome · Telefones · E-mail · Endereço.
Depois: **Solicitação** (texto corrido), **Providências realizadas** e **Conclusão**.

**Página 2 — Registro Fotográfico:** quadros de 2 fotos por linha, cada uma com uma linha de legenda abaixo.
No rodapé: **Status:** (Atendimento em andamento / Concluído / Não procede).

Pelo Orientador (item 10), a ficha é preenchida pela Comunicação, mantida atualizada e enviada em PDF, individualmente, no ANEXO 4.
