# Skills do projeto

As skills desta pasta vêm de [mattpocock/skills](https://github.com/mattpocock/skills) (licença MIT, ver `LICENSE-mattpocock-skills`), copiadas das pastas `skills/engineering` e `skills/productivity` no commit `24fe0ef`.

Elas estão aqui como skills do projeto porque o plugin "Skills For Real Engineers" não carrega nas sessões do Claude Code na nuvem. Ficando no repositório, elas valem em toda sessão deste projeto.

A configuração que elas usam (issues, etiquetas de triagem, documentos de domínio) fica em `docs/agents/` e está resumida no `CLAUDE.md`.

Para atualizar, copie de novo as pastas do repositório original.
